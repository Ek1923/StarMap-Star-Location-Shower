# Planet and Sun maps

Eleven texture maps, used by `shaders/planet.frag` to render the bodies in the 3D solar system
view.

**Source:** [Solar System Scope](https://www.solarsystemscope.com/textures/) (INOVE).
**Licence:** Creative Commons Attribution 4.0 International (CC BY 4.0).

CC BY 4.0 permits use, including commercially, and requires attribution. The app credits
"Solar System Scope" in its about text, and this file records the obligation so that a future
build cannot drop the credit without someone noticing.

The maps are themselves built from imagery by NASA, the USGS Astrogeology Science Center and the
ESA/Cassini and Messenger missions. The 2k versions are used rather than the 8k ones: eleven 8k
maps would add roughly 200 MB to the download for detail nobody can see on a planet that is 40
pixels across.

Downloaded 2026-10-03 and verified as real JPEG/PNG files by their magic bytes, not merely by a
200 response - a scripted download that lands an HTML error page is the usual way this goes
wrong.
