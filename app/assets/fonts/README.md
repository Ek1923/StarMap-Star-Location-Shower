# Spectral

`Spectral-Light.ttf`, `Spectral-Regular.ttf`, `Spectral-SemiBold.ttf`

Designed by Production Type for Google. Licensed under the **SIL Open Font License, Version 1.1**,
which permits bundling in an application, including a commercial one.

Fetched from `fonts.gstatic.com` on 2026-10-03 via the Google Fonts CSS API, at the URLs that API
returned for weights 300, 400 and 600. Verified as real TrueType files (`0x00010000` magic) rather
than an HTML error page, which is the usual failure mode of a scripted font download.

Bundled rather than loaded at runtime on purpose: the app is meant to work outside, at night,
possibly with no signal. A typeface that arrives over the network is a typeface that sometimes
does not.
